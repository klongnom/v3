# 🌱 10% Rule by Kong

> **“ออมก่อน ค่อยใช้”** (Pay Yourself First)  
> Web Application / PWA สำหรับจัดการการเงินส่วนบุคคลที่ใช้งานง่าย สะอาด ทันสมัย ออกแบบตามแนวคิด Mobile-First และทำงานได้โดยไม่ต้องมี Server (Local-First Architecture)

---

## 📌 จุดเด่นของแอปพลิเคชัน

1. **ออมก่อน ค่อยใช้ (Pay Yourself First)**: เมื่อบันทึกรายได้เข้ามา ระบบจะทำการจัดสรรเงินเข้าซองเงิน (Wallets) ต่างๆ ตามเปอร์เซ็นต์ทันที เช่น เงินออม 10%, เงินลงทุน 5%, เงินใช้จ่าย 85%
2. **Income Wizard 2 ขั้นตอน**: หน้าต่างบันทึกรายได้ที่เลือกแหล่งรายได้เดิมหรือเพิ่มใหม่ได้ สรุปยอดแบ่งเงินตามเปอร์เซ็นต์แบบ Real-time และปรับเปลี่ยนได้ก่อนยืนยัน
3. **ระบบ Wallet แบบ Dynamic**: ปรับเปลี่ยน เปอร์เซ็นต์ ชื่อ Emoji หรือเพิ่มซองเงินได้ (3-6 ซอง) พร้อมระบบป้องกันเปอร์เซ็นต์รวมเกิน 100%
4. **ป้องกันเงินใช้จ่ายเกิน (Overspend Protection)**: บันทึกค่าใช้จ่ายหักจากซองเงินใช้จ่ายเท่านั้น หากงบไม่พอระบบจะเตือนและปฏิเสธการบันทึก
5. **ระบบ Self Tax & Self Tax Fund**: หักภาษีตนเอง 10% จากค่าใช้จ่ายเพื่อสะสมใน Self Tax Fund เมื่อครบทุก 500 บาท ระบบจะเปลี่ยนเป็นเงินลงทุนโดยอัตโนมัติ
6. **💸 ระบบเงินให้ยืม & ติดตามหนี้ (NEW!)**:
   - บันทึกชื่อผู้ยืม, เงินต้น, อัตราดอกเบี้ย (% ต่อเดือน / ต่อปี), ระยะเวลา (ปี/เดือน)
   - คำนวณดอกเบี้ยแบบ Simple Interest อัตโนมัติ (เช่น 10,000 บาท ดอกเบี้ย 2% ต่อเดือน 6 เดือน = ดอกเบี้ย 1,200 บาท ยอดรวม 11,200 บาท)
   - หักเงินต้นออกจาก Wallet ที่ผู้ใช้เลือกอย่างถูกต้อง (ไม่นับเป็นค่าใช้จ่ายทั่วไป)
   - บันทึกการคืนเงินหลายครั้งพร้อมประวัติย้อนหลัง คืนเงินกลับเข้า Wallet ที่เลือก
   - แสดงสถานะชัดเจน: `🔴 ยังไม่ได้คืน`, `🟡 กำลังชำระ`, `✅ คืนครบแล้ว`
   - Lending Dashboard สรุปยอดกู้ทั้งหมด, ได้รับคืนแล้ว, ค้างอยู่, ดอกเบี้ยคาดการณ์ และดอกเบี้ยได้รับจริง
7. **เป้าหมายเงินก้อน & คะแนนวินัยทางการเงิน**: ติดตามเป้าหมายเงินออม (เริ่มต้น 30,000 บาท) พร้อมระบบคำนวณคะแนนวินัยการเงิน (0-100 คะแนน) แบ่งเป็น 4 ระดับ
8. **ระบบจัดการรายเดือน (Monthly System)**: สลับดูข้อมูลย้อนหลังเป็นรายเดือน พร้อมกราฟแบ่งเงินและบทวิเคราะห์สถานะทางการเงินประจำเดือน
9. **PWA & Offline Capable**: ติดตั้งบนมือถือ Android/iOS/PC ได้ ทำงานแบบ Offline ด้วย Service Worker ไม่ต้องล็อกอิน ข้อมูลเก็บใน LocalStorage ปลอดภัย 100%

## 🚀 โครงสร้างไฟล์ (File Structure)

```text
/
├── index.html        # โครงสร้างหน้าเว็บ Semantic HTML5 และ Modals
├── style.css         # ระบบดีไซน์ Vanilla CSS3 (Mobile First, Modern Dark Mode)
├── app.js            # Core Application Logic, LocalStorage, Engine & Calculations
├── manifest.json     # PWA Web App Manifest
├── sw.js             # Service Worker สำหรับ Offline Caching
└── README.md         # เอกสารคู่มือและการใช้งาน
```

## 🌐 การนำไปใช้งานบน GitHub Pages (Deployment)

1. สร้าง Repository ใหม่บน GitHub (เช่น `10percent-rule-kong`)
2. Upload หรือ Push ไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น Repository:
   - `index.html`
   - `style.css`
   - `app.js`
   - `manifest.json`
   - `sw.js`
   - `README.md`
3. ไปที่ **Settings** -> **Pages** ใน GitHub Repository
4. ในหัวข้อ **Source** ให้เลือก Branch `main` (หรือ `master`) และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอสักครู่ GitHub Pages จะสร้าง URL ให้ใช้งานได้ทันที เช่น `https://username.github.io/10percent-rule-kong/`

## 🧪 การทดสอบระบบ (Test Cases Verification)

คุณสามารถทดสอบการทำงานของระบบตามข้อกำหนดทั้ง 12 กรณีได้ดังนี้:

| Test Case | ขั้นตอนการทดสอบ | ผลลัพธ์ที่คาดหวัง |
| :--- | :--- | :--- |
| **TEST 1** | เพิ่มรายได้ 500 บาท | ซองออม (+50), ซองลงทุน (+25), ซองใช้จ่าย (+425) |
| **TEST 2** | เพิ่มรายได้ 4,500 บาท | ซองออม (+450), ซองลงทุน (+225), ซองใช้จ่าย (+3,825) |
| **TEST 3** | เพิ่มรายได้หลายครั้ง (500, 1000, 2000) | ยอดสะสมในซองเงินรวมเพิ่มขึ้นถูกต้องตรงตามสัดส่วน |
| **TEST 4** | ปรับ % เป็น ออม 15%, ลงทุน 10%, ใช้จ่าย 75% แล้วเพิ่ม 1,000 บาท | ได้ยอดแบ่ง: 150, 100, 750 บาท |
| **TEST 5** | พยายามตั้งเปอร์เซ็นต์ซองเงินเป็น 50 + 40 + 20 (รวม 110%) | ระบบปฏิเสธการบันทึกและแสดงข้อความเตือนเปอร์เซ็นต์รวมเกิน 100% |
| **TEST 6** | บันทึกค่าใช้จ่าย 100 บาท (ยอดเงินใช้จ่ายมี 500 บาท) | เงินใช้จ่ายคงเหลือเท่ากับ 400 บาท |
| **TEST 7** | บันทึกค่าใช้จ่าย 100 บาท พร้อมติ๊ก Self Tax 10% | ยอดหักจากเงินใช้จ่ายเป็น 110 บาท, Self Tax Fund เพิ่มขึ้น +10 บาท |
| **TEST 8** | ยอด Self Tax Fund มี 490 บาท เพิ่มค่าใช้จ่ายที่มี Self Tax อีก 20 บาท | Self Tax Fund เปลี่ยน 500 บาทเป็นเงินลงทุน, คงเหลือใน Fund 10 บาท |
| **TEST 9** | เปลี่ยนเปอร์เซ็นต์ซองเงินหลังมีรายการรายได้เก่าแล้ว | รายได้เก่ายังคงใช้การจัดสรรเดิม ไม่ถูกคำนวณย้อนหลัง |
| **TEST 10** | กด Refresh Browser | ข้อมูลทั้งหมดคงเดิม ไม่สูญหาย (LocalStorage) |
| **TEST 11** | ปล่อยกู้ 10,000 บาท ดอกเบี้ย 2%/เดือน 6 เดือน | ดอกเบี้ย 1,200 ยอดรวม 11,200 บาท หักเงินต้นจาก Wallet ที่เลือก |
| **TEST 12** | บันทึกคืนเงินกู้ 5,000 บาท | ยอดคืนเป็น 5,000 เหลือ 6,200 บาท สถานะ `🟡 กำลังชำระ` คืนเงินเข้า Wallet ที่เลือก |
